# JAGAT Data Center

Website statis untuk dipublikasikan menggunakan GitHub Pages.

## Cara publish
1. Buat repository baru di GitHub, misalnya `jagat-data-center`.
2. Atur repository menjadi **Public**.
3. Upload `index.html` ke root repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
7. Tunggu proses deployment selesai. GitHub akan menampilkan URL publik di halaman Pages.

Catatan: website ini adalah situs statis. Formulir, login, dan penyimpanan data yang membutuhkan backend tidak otomatis menjadi layanan server hanya karena dipublikasikan di GitHub Pages. Periksa juga kredensial demo sebelum memublikasikan repository.
